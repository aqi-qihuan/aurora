## 三、激进升级计划

### 阶段 1：安全紧急修复（必须）

**目标**：修复 Axios 安全漏洞 CVE-2026-40175

```
升级内容：
- axios: 1.16.0 → 1.15.1（安全补丁版）

风险：🟢 低
影响：API 兼容
测试：无需额外测试
```

> ⚠️ 注意：Axios 1.15.1 是安全修复版，API 与 1.16.0 完全兼容

### 阶段 2：平滑升级（低风险）

**目标**：升级无破坏性变更的依赖

```
升级内容：
- vue-router: 4.6.4 → 5.0.6
- pinia: 2.3.1 → 3.0.1

风险：🟡 低-中
说明：
  - Vue Router 5 官方称无破坏性变更
  - Pinia 3 仅移除 Vue 2 支持
  - pinia-plugin-persistedstate 需要同步升级到 4.x

关联升级：
- pinia-plugin-persistedstate: 3.2.3 → 4.7.1
```

### 阶段 3：TypeScript 大版本升级（中等风险）

**目标**：升级到 TypeScript 6.x

```
升级内容：
- typescript: 5.9.3 → 6.0.3

风险：🟡 中
可能需要：
  - 更新 tsconfig.json 配置
  - 调整类型定义
  - 重新检查 strict 模式报错
```

### 阶段 4：Vite 8.0 升级（高风险）

**目标**：跨 3 个大版本升级到 Vite 8

```
升级路径建议：
  Vite 5 → Vite 6 → Vite 7 → Vite 8

风险：🔴 高
挑战：
  1. 配置文件格式变化（vite.config.ts）
  2. 插件兼容性检查
  3. 构建输出变化
  4. 环境变量处理变化

必需同步升级：
  - vite-plugin-prismjs（检查兼容性）
  - vite-plugin-svg-icons（检查兼容性）

预估工时：2-4 小时
```

### 阶段 5：Tailwind CSS 4.x 升级（极高风险）

**目标**：从 Tailwind 2 升级到 Tailwind 4

```
升级路径：
  Tailwind 2.1.2 → Tailwind 3.x → Tailwind 4.x

风险：🔴🔴 极高
原因：
  1. CSS 类名系统完全重写
  2. 配置格式从 tailwind.config.js 变为 CSS-first
  3. 所有自定义样式需要迁移
  4. 组件样式大规模调整

预估工时：8-16 小时（视组件复杂度）
建议：评估是否必要，如非必需可暂不升级
```
