## 一、项目技术栈概览

### 核心技术
- **框架**: Vue 3 + TypeScript
- **构建工具**: Vite 5.0.0
- **路由**: Vue Router 4.0.3
- **状态管理**: Pinia 2.0.14
- **UI组件库**: Element Plus 2.2.9
- **样式方案**: Tailwind CSS 2.1.2 + SCSS
- **国际化**: Vue I18n 9.1.10

### 核心功能库
- **HTTP客户端**: Axios 0.27.2
- **Markdown渲染**: Markdown-it 13.0.1 + 多个插件
- **代码高亮**: Prism.js 1.28.0
- **图片预览**: v3-img-preview 1.1.16
- **无限滚动**: vue3-infinite-scroll-better 2.2.0
- **图片懒加载**: vue3-lazy 1.0.0-alpha.1

### ⚠️ Node.js 版本要求

**更新（2026-05-13）**：项目升级后需要 **Node.js v22+**

可用版本（通过 nvm 管理）：
- ❌ v16.20.2（旧版，不兼容）
- ❌ v17.3.1（旧版，不兼容）
- ❌ v18.17.0（不兼容，需要 v22+）
- ✅ **v24.15.0**（✅ 推荐，稳定）

> ⚠️ 重要：P2 升级后，`@vitejs/plugin-vue@6.0.6` 使用了 `crypto.hash` API，该 API 需要 Node.js v22+。

## 三、依赖版本对比与升级评估

### 🔴 重大版本升级（存在Breaking Changes）

#### 1. Vue Router
- **当前版本**: ^4.0.3
- **最新版本**: **5.0.6** (2026-04-22)
- **升级风险**: 🔴 高
- **Breaking Changes**: Vue Router 5.x 是重大升级，可能不兼容 4.x API
- **升级建议**: 
  - ⚠️ 需要详细查看迁移指南
  - 检查路由定义、导航守卫、动态路由等API变化
  - 建议分阶段：先升到 4.x 最新版，再考虑 5.x

#### 2. Vite
- **当前版本**: ^5.0.0
- **最新版本**: **8.0** (2026-03-12)
- **升级风险**: 🔴 高
- **Breaking Changes**: Vite 6/7/8 可能有重大API变化，构建配置、插件系统可能不兼容
- **升级建议**:
  - ⚠️ 需要同步升级所有Vite插件（@vitejs/plugin-vue, vite-plugin-prismjs, vite-plugin-svg-icons）
  - 检查 vite.config.ts 配置兼容性
  - 建议分阶段升级：5 → 6 → 7 → 8

#### 3. Pinia
- **当前版本**: ^2.0.14
- **最新版本**: **3.0.4** (2026-04)
- **升级风险**: 🔴 高
- **Breaking Changes**: Pinia 3.x 放弃 Vue 2 支持，移除废弃API
- **升级建议**:
  - 如果只使用 Vue 3，升级相对平滑
  - 需要检查 `pinia-plugin-persistedstate` 兼容性

#### 4. TypeScript
- **当前版本**: ~5.3.0
- **最新版本**: **6.0.3** (2026-03-23)
- **升级风险**: 🟡 中
- **Breaking Changes**: TypeScript 6.0 为 7.0（原生移植版）做过渡，可能有类型变化
- **升级建议**:
  - 先修复所有 TypeScript 类型错误
  - 检查第三方库的类型定义兼容性

#### 5. Tailwind CSS
- **当前版本**: 2.1.2 (通过 @tailwindcss/postcss7-compat)
- **最新版本**: **4.3.0** (2026-05-11)
- **升级风险**: 🔴 极高
- **Breaking Changes**: 
  - Tailwind CSS 3.x/4.x 有巨大变化
  - 配置文件格式变化（tailwind.config.js → tailwind.config.ts）
  - 可能需要 rewrite 所有 Tailwind 类
  - Just-in-Time (JIT) 模式成为默认
- **升级建议**:
  - ⚠️ 这是最复杂的升级
  - 建议使用官方迁移工具
  - 或者考虑暂时保持 2.x，只做安全更新

#### 6. Vue I18n
- **当前版本**: ^9.1.10
- **最新版本**: **11.4.0** (2026-04)
- **升级风险**: 🟡 中
- **Breaking Changes**: Vue I18n 10.x/11.x 可能有API变化
- **升级建议**:
  - 检查 `$t()`, `t()`, 复数规则等API变化
  - 查看语言文件格式是否兼容

## 五、升级风险与注意事项

### ⚠️ 高风险操作

1. **备份代码**
   - 升级前创建 Git 分支：`git checkout -b feat/upgrade-deps`
   - 或使用 Git tag 标记当前版本

2. **逐步升级**
   - 不要一次性升级所有依赖
   - 每次升级后运行完整测试
   - 遇到错误立即回滚

3. **测试覆盖**
   - 升级后必须测试所有页面
   - 重点测试：路由、状态管理、API请求、UI交互
   - 使用自动化测试（如果有）

4. **Tailwind CSS 升级成本**
   - 估计需要 3-5 天工作量
   - 需要熟悉 Tailwind 3.x/4.x 新特性
   - 建议使用官方迁移工具
